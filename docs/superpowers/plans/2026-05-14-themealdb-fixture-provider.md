# TheMealDB Fixture Provider Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate fixture-vs-live parse divergence for TheMealDB ingredient quantities/units by storing raw TheMealDB API JSON in the fixture and parsing it at load time via the live Rust `parse_measure` logic.

**Architecture:** Add a `pub parse_meal_json(serde_json::Value) -> Result<ExternalDish, serde_json::Error>` entry point to `themealdb.rs` that delegates to the existing private `MdbMeal` deserialization and `meal_to_dish` transformation. Add a debug-only `TheMealDbFixtureProvider` to the same file that reads raw TheMealDB meals from `lookup.json` and calls `parse_meal_json` at lookup time. Update the refresh script to store raw meal objects instead of running the `build_mdb_dish` jq transformation. Closes #812.

**Tech Stack:** Rust, `serde_json`, `rust_decimal`, `async_trait`, bash/jq.

```rust
// ---------------------------------------------------------------------------
// Fixture-backed provider (debug builds only)
// ---------------------------------------------------------------------------

/// Fixture-backed `RecipeProvider` for e2e tests.
///
/// Reads `search.json` (`HashMap<term, Vec<SearchResult>>`) for search and
/// `lookup.json` (`HashMap<idMeal, raw TheMealDB meal JSON>`) for lookups.
/// Ingredient quantities/units are parsed at load time by [`parse_meal_json`],
/// guaranteeing the same output as the live [`TheMealDbProvider`].
#[cfg(debug_assertions)]
pub struct TheMealDbFixtureProvider {
    search_path: std::path::PathBuf,
    lookup_path: std::path::PathBuf,
}

#[cfg(debug_assertions)]
impl TheMealDbFixtureProvider {
    pub fn new(
        search_path: std::path::PathBuf,
        lookup_path: std::path::PathBuf,
    ) -> Result<Self, ExternalProviderError> {
        if !search_path.is_file() {
            return Err(ExternalProviderError::ConfigurationError(format!(
                "fixture search file not found: {}",
                search_path.display()
            )));
        }
        if !lookup_path.is_file() {
            return Err(ExternalProviderError::ConfigurationError(format!(
                "fixture lookup file not found: {}",
                lookup_path.display()
            )));
        }
        Ok(Self {
            search_path,
            lookup_path,
        })
    }
}

#[cfg(debug_assertions)]
#[async_trait]
impl RecipeProvider for TheMealDbFixtureProvider {
    fn source_name(&self) -> &str {
        "themealdb"
    }

    #[tracing::instrument(
        name = "provider::themealdb_fixture::search_dishes",
        skip(self),
        fields(provider = "themealdb_fixture")
    )]
    async fn search_dishes(
        &self,
        query: &SearchQuery,
    ) -> Result<Vec<SearchResult>, ExternalProviderError> {
        let bytes = std::fs::read(&self.search_path).map_err(|e| {
            ExternalProviderError::ConfigurationError(format!(
                "failed to read fixture {}: {e}",
                self.search_path.display()
            ))
        })?;
        let by_query: HashMap<String, Vec<SearchResult>> = serde_json::from_slice(&bytes)
            .map_err(|e| ExternalProviderError::ResponseParseError(e.to_string()))?;
        let mut results = by_query
            .get(&query.query.to_lowercase())
            .cloned()
            .unwrap_or_default();
        results.truncate(query.limit as usize);
        Ok(results)
    }

    #[tracing::instrument(
        name = "provider::themealdb_fixture::get_dish_by_id",
        skip(self),
        fields(provider = "themealdb_fixture", external_id = %external_id)
    )]
    async fn get_dish_by_id(
        &self,
        external_id: &str,
    ) -> Result<Option<ExternalDish>, ExternalProviderError> {
        let bytes = std::fs::read(&self.lookup_path).map_err(|e| {
            ExternalProviderError::ConfigurationError(format!(
                "failed to read fixture {}: {e}",
                self.lookup_path.display()
            ))
        })?;
        let lookup: HashMap<String, serde_json::Value> = serde_json::from_slice(&bytes)
            .map_err(|e| ExternalProviderError::ResponseParseError(e.to_string()))?;
        match lookup.get(external_id) {
            None => Ok(None),
            Some(value) => parse_meal_json(value.clone())
                .map(Some)
                .map_err(|e| ExternalProviderError::ResponseParseError(e.to_string())),
        }
    }
}
```

- [ ] **Step 1: Replace the TheMealDB section**

In `scripts/refresh-catalog-fixtures.sh`, replace everything from `# ── TheMealDB ──...` through `echo "${mdb_lookup_acc}" | jq '.' > "${mdb_dir}/lookup.json"` with:

```bash
# ── TheMealDB ─────────────────────────────────────────────────────────────────
# Search: https://www.themealdb.com/api/json/v1/<key>/search.php?s=<term>
#
# search.json: HashMap<term, Vec<SearchResult>> — same shape as dtos::SearchResult.
# lookup.json: HashMap<idMeal, raw TheMealDB meal object> — parsed at load time
#   by TheMealDbFixtureProvider via parse_meal_json(), which applies the same
#   parse_measure() and category_to_occasion_tags() logic as the live provider.
echo "→ TheMealDB: capturing search.json and lookup.json"
mdb_search_acc='{}'  # keyed by lowercased query term
mdb_lookup_acc='{}'  # keyed by idMeal

for term in "${DISH_TERMS[@]}"; do
    encoded="$(urlencode_term "${term}")"
    raw="$(curl -fsSL "https://www.themealdb.com/api/json/v1/${MEALDB_KEY}/search.php?s=${encoded}")"

    normalized="$(jq '[.meals[]? | {
        external_id: .idMeal,
        name: .strMeal,
        description: .strCategory,
        thumbnail_url: .strMealThumb
    }]' <<<"${raw}")"
    term_lower="$(printf '%s' "${term}" | tr '[:upper:]' '[:lower:]')"
    mdb_search_acc="$(jq --arg key "${term_lower}" --argjson new "${normalized}" '. + {($key): $new}' <<<"${mdb_search_acc}")"

    entries="$(jq --argjson empty '{}' '
        reduce (.meals[]? // empty) as $m ($empty;
            . + {($m.idMeal): $m}
        )
    ' <<<"${raw}")"
    mdb_lookup_acc="$(jq --argjson new "${entries}" '. * $new' <<<"${mdb_lookup_acc}")"
done

echo "${mdb_search_acc}" | jq '.' > "${mdb_dir}/search.json"
echo "${mdb_lookup_acc}" | jq '.' > "${mdb_dir}/lookup.json"
```
